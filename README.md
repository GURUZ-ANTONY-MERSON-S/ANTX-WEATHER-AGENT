# 🌦️ ANTX Weather AI Agent

A simple AI-powered weather assistant built using **n8n**, **Google Gemini AI**, and the **OpenWeather API**. Users can ask weather-related questions through a modern web interface and receive intelligent, real-time weather information.

## 🌐 Live Demo

https://antx-weather-agent.vercel.app/

## 🚀 Features

- 🌤️ Current weather information
- 🌧️ Rain and weather condition analysis
- 🌡️ Temperature and humidity details
- 💨 Wind speed information
- 🤖 AI-powered weather responses using Google Gemini
- ⚡ Automated workflow built with n8n
- 📱 Responsive web interface
- 🌍 Search weather for cities worldwide

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- n8n
- Google Gemini AI
- OpenWeather API
- Vercel

## 📌 How It Works

1. User enters a weather-related question.
2. The request is sent to an n8n AI workflow.
3. Google Gemini processes the query.
4. OpenWeather API provides live weather data.
5. The AI generates a user-friendly response.
6. The response is displayed on the website.

## 📷 Project Workflow

User → Website → n8n AI Agent → Google Gemini → OpenWeather API → AI Response → User

## 🎯 Project Goal

To provide an intelligent and easy-to-use weather assistant that delivers accurate weather information using AI and real-time weather data.
